# Огонь и вода — Canvas-платформер

Проект работает на HTML, CSS и ванильном JavaScript Canvas. Архитектура `Game.js` / `Player.js` / `input.js` / `collision.js` сохранена. Основа всех трёх карт перенесена из второго проекта; добавлены отдельные старты и выходы для четырёх стихий, а недоступная кнопка у края второй карты перенесена в игровую область.

## Запуск

1. Распакуйте архив и откройте папку проекта в VS Code.
2. Запустите `index.html` через Live Server.
3. Нажмите «Играть» и выберите один из трёх уровней. Все три уровня доступны сразу.

## Управление

| Персонаж | Движение | Прыжок |
|---|---|---|
| Огонь | `A` / `D` | `W` |
| Вода | `←` / `→` | `↑` |
| Земля | `J` / `L` | `I` |
| Воздух | `F` / `H` | `T` |

На телефоне выберите персонажа в панели сенсорного управления, затем используйте кнопки движения и прыжка. Воздух умеет делать двойной прыжок.

## Карта уровня

Каждая строка в `LEVEL_MAPS` — ряд клеток 20 × 20 пикселей. Расположение исходных платформ, опасных зон и барьеров сохранено; дополнительные старты и выходы отмечены отдельными символами.

| Символ | Значение |
|---|---|
| `0` | Пустая клетка |
| `1` | Стена или пол |
| `9` / `8` / `7` / `6` | Старт Огня / Воды / Земли / Воздуха |
| `v` / `V` / `E` / `A` | Выход Огня / Воды / Земли / Воздуха |
| `P` | Лава: безопасна для Огня |
| `G` | Вода: безопасна для Воды |
| `B` | Кислота: безопасна для Земли |
| `q` / `a` / `z` | Цветные нажимные кнопки |
| `w` / `e` | Вертикальный / горизонтальный барьер кнопки `q` |
| `s` / `d` | Вертикальный / горизонтальный барьер кнопки `a` |
| `x` / `c` | Вертикальный / горизонтальный барьер кнопки `z` |

Кнопки окрашены в цвета стихий, которые могут их нажимать. Зелёная кнопка `q` по умолчанию реагирует на Землю, голубая `a` — на Воздух, а разделённая красно-синяя `z` — на Огонь и Воду. Во втором уровне синяя `q` находится в нижней комнате: Вода может удерживать её, пока Огонь и Воздух проходят к верхним выходам. Кнопку `a` в этом уровне нажимают Огонь и Воздух. В третьем уровне кнопка `a` на нижнем маршруте доступна Воде и Воздуху, чтобы Вода могла открыть барьер на пути к своему выходу.

Символы барьеров повторяют устройство второго проекта: `w`, `s`, `x` занимают клетку шириной и три клетки высотой; `e`, `d`, `c` — три клетки шириной и одну высотой. Пока кнопка удерживается подходящим персонажем, связанные барьеры открыты. Кнопочная платформа остаётся неподвижной в коллизиях: сжимается только её видимая пластина. Поэтому персонажа не просаживает в пол и не сталкивает с кнопки. Одноимённые кнопки работают как одна группа и открывают связанные барьеры.

Опасные участки рисуются непосредственно на карте: лава — оранжево-красная, вода — синяя, кислота — зелёная. Воздух не защищён от этих жидкостей и должен их обходить.

Чтобы изменить расположение клеток, отредактируйте массив `LEVEL_MAPS` в начале `Game.js`.
